# Contributing

## Flujo

1. Crear issue/tarea con criterios de aceptación.
2. Branch corta desde `develop` o estrategia acordada.
3. Implementar una vertical slice.
4. Tests + lint + typecheck.
5. PR con screenshots cuando cambie UI.
6. Revisión obligatoria para migraciones, auth, pagos y permisos.

## Commits sugeridos

Conventional Commits (`feat:`, `fix:`, `refactor:`, `test:`, `docs:`, `chore:`).

## Pull Request

Explicar:

- problema;
- solución;
- archivos/migraciones;
- pruebas ejecutadas;
- riesgos;
- rollback si aplica.
