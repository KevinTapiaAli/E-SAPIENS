# Security Policy

No publicar vulnerabilidades, secretos o credenciales en issues públicas.

## Prohibido en Git

- passwords reales;
- API keys;
- private keys;
- tokens;
- cookies;
- dumps de producción;
- datos personales de usuarios reales.

## Antes de producción

Realizar revisión de auth, autorización, uploads, pagos, webhooks, almacenamiento privado, configuración CORS/CSRF, headers, secretos y backups.
