# Roadmap propuesto

Fecha de referencia del documento: septiembre de 2026.

## Hito 1 — Demo técnica (finales de septiembre / inicios de octubre de 2026)

Objetivo: demostrar arquitectura y flujo vertical, no toda la plataforma.

Debe incluir:

- monorepo ejecutable;
- login/registro/aprobación;
- catálogo;
- un curso con módulos/lecciones;
- progreso básico;
- dashboard estudiante;
- API documentada;
- DB migrada;
- despliegue de staging.

## Hito 2 — Beta funcional (noviembre-diciembre de 2026)

- docente;
- evaluaciones;
- tareas;
- clases y grabaciones;
- pagos en sandbox/proveedor definido;
- certificados;
- notificaciones;
- dashboards administrativos;
- pruebas con usuarios.

## Hito 3 — Lanzamiento (enero de 2027)

Condicionado a:

- UAT aprobado;
- seguridad revisada;
- proveedor de pago validado;
- backups/restore;
- observabilidad;
- pruebas de carga;
- políticas/privacidad;
- dominio, SSL, correo transaccional;
- runbook y responsables.

## IA

No bloquear el lanzamiento por una red neuronal. Lanzar recomendaciones por reglas y evolucionar a ML con datos reales y evaluación posterior.
